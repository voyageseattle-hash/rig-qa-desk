**Title:** Rig QA Desk  
**Tagline:** Catch rig export faults, review NVIDIA advice, and keep a verifiable artist handoff.  
**Proposed track:** Best Apps and Agents.

## Problem and value

A rigged character can look ready while its export contains an invalid bone reference or an animation declaration that does not add up. A vague import error gives the artist little direction; an AI explanation can sound convincing while misreading the evidence. Rig QA Desk turns supported measurements into an investigation and a traceable handoff. Production time savings and a finished-character certificate have not been established.

## What it does

The independent Node companion inspects an owned/licensed self-contained GLB, runs bounded structural/numeric checks and a separate official Khronos conformance report, and binds findings to file hashes and locations. NVIDIA Nemotron via Nebius Token Factory supplies evidence-linked investigation advice. A human accepts, defers or rejects suggestions and exports the decision with asset, report and advice identity. Accepting advice does not authorize repair.

The approved hosted v7 also provides a **local** character/motion panel and CLI with profile-based symmetry, hinge, sampled deformation, foot-plane, clip-continuity and paired-contact/support measurements. Thresholds, intentional exceptions, missing rules, unsupported features and work/sampling limits remain explicit. Files and profiles in this panel are not uploaded or sent to NVIDIA. This is broader than the old structural-only screen, but it does not certify anatomy, rendered quality, physical correctness or game-engine behavior.

The separate guided hosted AI route uses fixed owned procedural fixtures. It does not accept arbitrary character uploads and does not run the companion's official validator.

## Demonstrated workflow and model boundary

The owned fixture has 24 bone slots, a surface-point reference to invalid slot 24 (valid 0–23), and 22 declared translation samples for 23 timestamps. All 23 vectors remain in the binary. Fresh checks locate these controlled faults. A separately prepared corrected export yields two-to-zero companion findings and three-to-zero official errors. No uploaded asset is repaired or private game asset distributed.

The adapter pins `nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B` at the Nebius Token Factory chat-completions endpoint. Only the server-generated structured companion findings are sent. Response schema/hash/reference/action checks do not prove factual accuracy. A historical explanation blamed a valid zero timestamp rather than duplicate timestamps; it was rejected. The demo defers animation uncertainty that the controlled fixture's evidence resolves. Measurements and model prose remain separate.

The new October 20 cut is actual newly recorded **local public-baseline** UI use: inspection, evidence, accept/defer decisions, actual downloaded review and prepared-export recheck. Its real October 12 NVIDIA response is clearly labeled **recorded**; it is not new inference and does not demonstrate every v7 feature. The old public video uses historical hosted captures. Neither is described as a fresh paid run.

## Platform feedback

**Token Factory:** The compatible endpoint enabled a small server adapter. Structured output rejected `uniqueItems`; removing it only from provider grammar while keeping local enforcement resolved that issue. A supported-keyword list and schema preflight would reduce diagnostic requests. One bounded call and no automatic retries simplify failure reasoning.

**NVIDIA:** Finding-linked output is useful but still needs factual review. Plausible incorrect wording and unsupported uncertainty belong in quality tests, alongside malformed JSON. Our former filter also misread “cannot guarantee”; the saved response was revalidated offline after a narrow fix.

**AI Cloud:** Not used or benchmarked. No deployment-speed, GPU-availability or cloud-performance claim is made.
