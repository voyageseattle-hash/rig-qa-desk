## Architecture and evidence boundaries

The slice is a loopback Node server and browser UI, pure bounded GLB inspector, a terminable local official-validator worker, strict report/advice schemas, one server-side NVIDIA request through Token Factory, and hash-bound review exports. The app is independently runnable with Node.js 22+ and npm. It does not invoke a hidden private backend.

Measured companion checks, official conformance findings and model suggestions remain distinct. The new official report is included in the measured-check export but is not sent to the model or folded into historical AI evidence. A hierarchy warning calls for review in the target engine, not automatic reparenting or applying scale. The app preserves input bytes and has no repair endpoint.

The pinned official validator is `gltf-validator@2.0.0-dev.3.10` under Apache-2.0. Validation has a five-second deadline, a terminable worker, bounded messages and one upload inspection at a time. External resources are always refused. A timeout, failure, truncation or unsupported check is not a pass. Model requests are also bounded and never silently retried or switched to another model.
