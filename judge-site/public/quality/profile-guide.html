Character allowances

Use Read rig and prepare allowances to get zero-based node and animation indices. The starting profile pairs unambiguous Left/Right and L/R names and selects up to four clips. Review it: names and default thresholds do not establish intended anatomy.

Raw GLBs and profiles remain in the local browser worker. No model request is made. Reports bind the exact character, counterpart, profile and measured output with SHA256. A saved profile bound to another file is rejected.

Results and sampling

Measured means the configured data was evaluated at reported poses. Partial means unsupported data or a work limit prevented completion. Not checked means required rules or data were absent. No result certifies visual or physical quality.

Core glTF uses metres and Y-up. Distances use evaluated GLB world coordinates including node scales; times are seconds and angles degrees. clips selects at most eight animations. samplesPerClip adds 2–48 uniform samples; animation keys and interval midpoints are included within the 256-pose total budget. Unselected clips and limits remain explicit. Contact/support intervals use evenly spaced samples.

Rest symmetry

"symmetry": {
  "pairs": [[3, 8], [4, 9]], "relativeTolerance": 0.10,
  "ignoredPairs": [],
  "surface": {"axis": 0, "plane": 0, "tolerance": 0.01,
              "maxUnmatchedFraction": 0.05}
}

Joint segments run from each node's parent to that node. Relative difference is absolute length difference divided by the larger length. Record intended asymmetry in ignoredPairs. Optional surface symmetry mirrors evaluated rest vertices around the explicit axis/plane and checks nearby points within tolerance. It does not infer bone tails, topology correspondence or intended anatomy. A posed model may need a different plane or no surface rule.

Signed hinge limits

"jointLimits": [{"parent": 5, "joint": 4, "child": 3,
  "axis": [0, 0, 1], "minDegrees": -5, "maxDegrees": 135,
  "relativeToRest": true}]

Use a direct three-node chain. The hinge axis is in the parent node's local coordinates. Positive bend follows the right-hand rule; by default the rest bend is subtracted. Set relativeToRest: false for the direct signed angle. Verify sign and intended range on a known pose; knee/elbow semantics are not guessed.

Mesh deformation and foot penetration

"deformation": {"minEdgeRatio": 0.25, "maxEdgeRatio": 2.5,
                "minAreaRatio": 0.10},
"ground": {"axis": 1, "height": 0, "tolerance": 0.01,
           "feet": [{"node": 6, "point": [0, -0.03, 0]}]}

Triangle edge lengths and areas are compared with the evaluated rest mesh, using linear-blend skinning, inverse bind matrices and up to four joint influences. Configure intentional squash/stretch. The foot point is local to its node: place it at the intended sole. Measuring a joint above the plane does not prove visible foot clearance.

Motion and clip joins

"motion": {"maxJointDegreesPerSecond": 1080,
           "maxNodeUnitsPerSecond": 10},
"transitions": [{"from": 0, "to": 1, "nodes": [0, 3, 6],
  "maxDistance": 0.05, "maxAngleDegrees": 20,
  "alignRootTranslation": false}]

Motion rates compare sampled world positions and local quaternion rotations. A transition compares source end to destination start, or explicit fromTime/toTime. Optional alignRootTranslation subtracts each endpoint's rootNode position (first hierarchy root by default). It aligns translation only, not heading. Gameplay states and engine blends are not inferred.

Two-character grip and release

"otherTransform": {"translation": [0, 0, 0],
  "rotation": [0, 0, 0, 1], "scale": [1, 1, 1]},
"contacts": [{"aNode": 3, "bNode": 9,
  "animation": 0, "otherAnimation": 0, "start": 0.2, "end": 0.7,
  "pointA": [0, 0, 0], "pointB": [0, 0, 0],
  "maxDistance": 0.03, "maxDrift": 0.02, "phase": "grip"}]

Select a counterpart GLB. Points are local to their respective nodes. Counterpart placement is outside its evaluated world transform. Both clips use the same configured times; timeline synchronization is not inferred. Gap is point distance; drift is change in their relative vector from the interval start. Use phase: "release" with a single instant (start === end) or interval for release alignment.

Landing support

"landings": [{"node": 6, "point": [0, -0.03, 0],
  "animation": 1, "start": 0.7, "end": 1, "axis": 1,
  "height": 0, "tolerance": 0.01, "maxSlide": 0.03}]

Use intervals where the anchor must remain planted. This measures absolute plane distance and horizontal drift from the interval start. It does not establish balance, weight or contact forces.

Bounds and unsupported data

Limits: 32 MiB per GLB, 4 MiB JSON, 1,024 nodes, 64 clips, two million decoded scalars, 30,000 evaluated vertices, three million work units, 256 poses, 128 findings, 64 KiB profiles and a 15-second terminable worker. Sparse/compressed accessors, required extensions, morph animation and additional influence sets are rejected or excluded with explicit incomplete coverage. External buffers are never fetched.

Materials, self-intersection, collisions, continuous-time extrema, engine overrides, cloth and physics remain separate reviews. Original files are never repaired. A measured export records no human approval.
