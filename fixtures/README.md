# Owned procedural fixtures

`node fixtures/generate.mjs` writes a triangle with a two-joint skeleton and one
translation animation, plus a deliberately flawed variant. They are generated
from numeric arrays in this directory; no Cast modules or external assets are
used. These are structural test data, not anatomical or deformation proofs.

The owner approved MIT licensing for this generator and its generated procedural
fixtures on October 12, 2026. See the companion's `LICENSE` and `NOTICE`.

Tests and the local server can import `buildFixture(options)` without writing any
files. Options: `timeValues`, `jointValues`, `outputType`, `interpolation`, and
`mutate(document, binary)`. The mutation callback operates only on freshly created
fixture data. `encodeGlb(document, binary)` supports malformed test fixtures.

Reference: [Khronos glTF 2.0 specification](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html).
# Export-workflow fixture

`workflow.mjs` independently generates an owned ribbon mesh with24 bones,48 vertices and two23-frame animation tracks. It is a structural workflow test, not a production character or visual benchmark. The valid variant has no companion findings or official validator diagnostics. Its flawed variant deliberately references joint24 outside slots0–23 and declares22 translation samples for23 timestamps. Binary values remain present: the simulated fault is a missing declared sample, not physically truncated bytes.

The generator and its outputs fall within this companion's MIT procedural-fixture scope. No private character geometry, names, textures or derivatives are included. Run the UI's **Run export-workflow demo** to inspect freshly generated bytes and replay the hash-matched real model response with review decisions unset.
